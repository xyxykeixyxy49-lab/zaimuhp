# 表記ガイドライン（登録商標・NGワード）

ホームページ・チラシ・SNS・資料など、外部に出すすべての文章はこのガイドラインに従う。
公開前に `node tools/check-terms.mjs` を実行し、エラー 0 件を確認すること。

> 出典：戦略MG研究会資料「戦略MGマネジメントゲームの沿革／登録商標」ページと手書きメモ（2026-11 時点）。
> 不明点は自己判断せず、株式会社戦略MG研究所に確認してから使う。

---

## 1. 基本ルール

1. **「戦略MG」を使う**。単に「MG」「マネジメントゲーム」とは書かない。
2. **初出に ® を付ける**：ページ内で最初に出てくる箇所を「戦略MG®」とし、※印を付ける。
3. **ページ末尾（フッター）に注記を入れる**：
   ```
   ※「戦略MG®」は、株式会社戦略MG研究所の登録商標です。
   ```
4. 他の登録商標（下表）を使う場合も、表記は**一字一句そのまま**。略さない・言い換えない・別の語と合成しない。

## 3. NGワード（使用禁止）

| NGワード | 理由・メモ | 代わりに使う表現 |
|---|---|---|
| マネジメントゲームMG | 他社（株式会社マネジメントカレッジ）系の名称。「マネジメント…ゲーム」を含む類似表現も避ける | 戦略MG / 戦略MGマネジメントゲーム |
| マネジメントゲーム（単独） | 上記と混同されるため | 戦略MGマネジメントゲーム |
| 戦略会計 | 他社系の名称 | （会計を説明する場合）「戦略MGで学ぶ会計」など一般表現 |
| STRAC | 同上 | 同上 |
| 戦略MG会計 | 西研究所系の名称。NG | 同上 |
| MG（単独・「戦略」なし） | 「マネジメントゲームMG」と混同される | 戦略MG |

### ⚠ 要確認事項

- **「戦略会計STRAC」**：登録商標一覧（戦略MG研究所）には載っているが、手書きメモでは「戦略会計」「STRAC」がNGワード扱い。
  → **確認が取れるまでホームページでは使わない**（チェックツールもエラー扱い）。
- 沿革（ソニー／東京通信工業、盛田氏、西順一郎氏、1973年改良版 等）は経緯が複雑で、過去に知的財産をめぐる内容証明のやり取りがあった旨のメモあり。
  → **他社・他団体・個人名を含む沿革はホームページに載せない**。載せる場合は戦略MG研究所の公式表記に合わせ、事前に確認を取る。
