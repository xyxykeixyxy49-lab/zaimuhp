# 動き・画像・動画素材のガイド

最終更新：2026-11-23

## 1. サイトの「滑らかな動き」（実装済み）

参考：MDS（mds-fund.com）。Wix の背景動画・スクロール演出を、本サイトでは自前の仕組みで再現している。

| 演出 | 中身 | 付け方（HTML属性） |
|---|---|---|
| 慣性スクロール | Lenis でホイール操作を滑らかに | 自動（全ページ） |
| 全画面の背景動画＋奥へ吸い込まれる | スクロールに合わせて背景が拡大・暗転、文字が上へ抜ける | `data-hero` / `data-hero-media` / `data-hero-content` |
| 見出しが1文字ずつ浮かぶ | 句読点は前の文字とくっつけて禁則を守る | `data-split` |
| 要素がふわっと出る | 下から20〜40px＋フェード | `class="reveal"` |
| カードが順番に出る | 子要素を0.12秒ずつずらして表示 | 親に `data-stagger` |
| 画像が幕が開くように出る | 角丸の枠が広がる | `data-img-reveal` |
| 視差（パララックス） | 画像が背景より遅れて動く | `data-parallax="0.25"`（数字が大きいほど大きく動く） |
| 流れる帯（マーキー） | 開催地や英単語が横に流れる | `.marquee` / `.marquee__track` |
| 画像のホバー拡大 | マウスを載せるとゆっくり拡大 | 親に `.zoom-hover` |
| ヘッダーの出し入れ | 下へスクロールで隠れ、上へ戻すと出る | 自動 |
| ページ切り替え | ふわっとフェード（Chrome・Safari の対応版） | 自動 |

- 処理は `src/scripts/motion.ts`、見た目は `src/styles/global.css` の「動き」の節。
- スマホやPCで「視差効果を減らす」を設定している人には、動きを付けずにすぐ表示する。
- JavaScript が読み込めなかった場合も、3秒後には内容が表示される。


## 3. 写真・実写風の素材について

**人物やビジネスシーンの写真は、AI生成か撮影・素材サイトが必要**（Claude 単体では作れない）。

### Canva（接続済み）で生成する場合

Canva の画像生成は「依頼者の言葉どおり」に作る仕組みのため、具体的な場面を指定すると狙いどおりになる。
下のような文で依頼すると良い（Claude に「この文で作って」と伝えればそのまま生成できる）。

| 用途 | 依頼文の例 |
|---|---|
| トップ・研修紹介 | 日本人の経営者や会社員6人が会議室のテーブルを囲み、カードやコマを使ったボードゲーム形式の経営研修に笑顔で取り組んでいる写真。自然光、青とオレンジのアクセント、文字なし |
| 士業向け | 日本人の税理士が中小企業の経営者と決算書のグラフを見ながら対話している写真。落ち着いたオフィス、ブルー系、文字なし |
| 経営者向け | 夜明けの東京の高層ビル街を、オフィスの窓から見下ろす日本人の経営者の後ろ姿。朝焼けのオレンジと濃紺の空、文字なし |
| 法人研修 | 研修室で講師が日本人社員に向けて説明し、受講者がメモを取っている写真。明るく清潔感のある雰囲気、文字なし |

注意：AI生成の人物は実在しない。研修の「実際の様子」として誤解されないよう、受講者の声や実績の横には使わない。本番では**実際の研修風景の写真**への差し替えを推奨（撮影時は写る人の掲載許可を取る）。

## 4. 専用ツールでの作り方（提案）

| やりたいこと | おすすめツール | 特徴・向いている人 | 費用感（目安・変わることあり） |
|---|---|---|---|
| ビジネス写真のAI生成 | **Canva**（接続済み）／Adobe Firefly | Canva は日本語指示で手軽。Firefly は商用利用の権利がクリアで、写真の質感が高い | Canva Pro 月1,180円〜／Firefly はAdobeプランに含まれる |
| 実写風の短い動画（人物・オフィス） | **Google Veo**（Gemini）／Runway／Kling／Canva の動画生成 | 文章や写真から5〜10秒の映像を作る。HPの背景やSNS広告向け | 月20〜30ドル前後〜 |
| 素材写真・動画をそのまま使う | PIXTA（日本人モデルが豊富）／Adobe Stock／Unsplash・Pexels（無料） | 実在のモデルで安心感がある。日本人の研修風景なら PIXTA が探しやすい | 1点数百円〜／無料 |
| 動画編集・テロップ入れ | **CapCut**／Canva／Premiere Pro | スマホで完結するなら CapCut。セミナー告知動画やリールに | 無料〜 |
| HPのデザインを自分で触りたい | **Figma**（設計）／STUDIO・Framer（ノーコード） | MDS のような動きをノーコードで作るなら STUDIO（日本製）や Framer。ただし今の顧客DB・LINE連携は作り直しが必要 | 無料〜月数千円 |
| 動きの細かい調整 | GSAP（使用中）・Lottie | 図解アニメやアイコンの動き。Lottie は After Effects で作った動きを軽く載せられる | 無料 |

### おすすめの進め方

1. **今**：Claude 作成の素材（ブランド動画・静止画）で全体の雰囲気を確定する。
2. **次**：Canva で研修シーンの写真を数枚生成し、たたき台として差し込む（上の依頼文を使う）。
3. **本番前**：初回セミナーでプロのカメラマンに撮影を依頼し、実写に差し替える。
   動画は、撮影素材を CapCut や Canva でつなぎ、15〜30秒の紹介動画にする。
4. 撮影・生成した素材は Google ドライブ「02_素材」に置き、Claude に「この写真を〇〇に使って」と伝えれば、サイトに組み込む。

## 5. Gemini（Veo）で動画を作る指示文

Gemini アプリ（gemini.google.com）の「動画」から Veo で作る。1回で8秒前後の動画ができる。
下の指示文をそのまま貼り付けて使う（Claude が調整済み）。うまくいかない場合は、結果を Claude に見せれば指示文を直す。

**共通のコツ**
- 「文字・ロゴを入れない」と必ず書く（AIは文字が崩れやすい。テロップは後から CapCut や Canva で入れる）
- HPの背景用は「無音」「ゆっくりしたカメラの動き」「最初と最後が似た構図」にすると、繰り返し再生しても不自然にならない
- 人物の口の動きに合わせたセリフは避け、環境音か無音にする

### ① HPトップの背景（横16:9・無音）
```
夜明けの東京。高層オフィスの大きな窓から、朝焼けに染まるビル街を見渡す映像。
濃紺の空が地平線からオレンジ色に明るくなっていく。カメラは窓際をゆっくり横に移動する（スライド）。
室内は暗めで、窓の外の光が主役。人物なし。文字・ロゴなし。
写実的な映像、落ち着いた高級感、色味は濃紺・ブルー・オレンジ。無音。横長16:9。
```

### ② 研修の様子（横16:9・環境音のみ）
```
明るい会議室で、日本人の経営者や会社員6人（30〜50代の男女）が大きなテーブルを囲み、
盤面・色とりどりのコマ・カード・電卓を使ったボードゲーム形式の経営研修に取り組んでいる。
1人がコマを動かし、周りが身を乗り出して笑顔で議論する。カメラはテーブルの周りをゆっくり回り込む。
窓からの自然光、ビジネスカジュアル、写実的な映像、差し色に青とオレンジ。
文字・ロゴなし。音は会議室の環境音と小さな話し声のみ（はっきりしたセリフなし）。横長16:9。
```

### ③ 税理士・会計士向け（横16:9・環境音のみ）
```
落ち着いたオフィスで、日本人の税理士が中小企業の経営者に、タブレットに表示した決算書のグラフを見せながら説明している。
経営者がうなずき、納得した表情になる。カメラは二人の手元から表情へゆっくり寄っていく。
青を基調にした清潔感のある空間、柔らかい自然光、写実的な映像。文字・ロゴなし。環境音のみ。横長16:9。
```

### ④ SNS・公式LINE用（縦9:16・環境音のみ）
```
日本人のビジネスパーソンが研修会場の入口から会議室に入り、テーブルの上の経営ボードゲームの盤面を見て笑顔になる。
カメラは後ろから追いかけ、最後に盤面のコマとカードに寄る。朝の明るい光、前向きでワクワクする雰囲気。
写実的な映像、差し色に青とオレンジ。文字・ロゴなし。環境音のみ。縦長9:16。
```

**使い方の注意**：AIで作った人物は実在しない。「実際の研修の様子」と誤解されないよう、受講者の声・実績の横には使わない。
作った動画は Google ドライブ「02_素材」に入れ、Claude に「この動画をトップに使って」と伝えればサイトに組み込む（HP背景用は Claude が軽量化・ループ用に加工する）。
